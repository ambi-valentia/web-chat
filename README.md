# Welcome to Web Chat!

This is a web chat application with private chats as well as group chats. 
- React frontend features adaptive design, skeleton loading, autoscroll and cute avatars!
- Express.js backend handles user message posting, generates random users and messages on load and chat history on demand.

Try it yourself now: https://ambi-valentia.github.io/web-chat/
